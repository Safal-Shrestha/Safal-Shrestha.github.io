# Safal Shrestha - Portfolio v1

This is Safal Shrestha's personal portfolio: an evolving record of projects, systems, engineering decisions, interests, and work beyond software.

The portfolio is intended to show how I think and what I am building, rather than simply list technologies or job titles. It brings together selected work, short reflections, and a journal that will grow as the portfolio develops.

## Still in the making

This is an active work in progress. Some sections are incomplete, some project details are still being refined, and additional features are planned. The current version is a foundation for the portfolio, not its finished form.

Planned additions may include:

- More detailed project case studies and live project links
- A fuller journal and archive of technical notes
- Additional work, experiments, and non-software interests
- Improved navigation and interactive features

## What this is not

This is not a tutorial, course, template, or complete catalogue of every project I have worked on. It is not meant to present a finished or exhaustive professional profile. The content and design will continue to change as the portfolio takes shape.
